# docs/images

Clean product screenshots are captured manually and saved in this folder as:

- `home.png` — the website home page with the catalogue preview
- `catalogue.png` — the full product catalogue
- `product-details.png` — a single product-details page

Capture them in a fresh browser window with no unrelated tabs visible (a private window works well), at 100% zoom, and save as PNG at these exact filenames so the root README picks them up.
